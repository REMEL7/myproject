- 한글 자막을 명시적인 글꼴로 직접 렌더링하고, 글자 단위로 끊기던 줄바꿈을 어절 단위로 정리했습니다.
- 제목·본문·보조 설명의 글자 크기와 위치를 통일했습니다.

- 도착 확인 → 재실행 후 복원 → 방문 완료 → 다음 장소 순으로 흐름을 정리했습니다.
- 재실행 과정의 빈 화면을 잘라내고, 장면 전환 시간과 인코딩 설정을 통일했습니다.

## 촬영 범위와 제출 자료

- 휴대폰 웹 구간은 실제 화면 캡처이고, 차량 앱 구간은 Pleos Connect 에뮬레이터의 실제 조작 녹화입니다.

- 기획서는 개인정보가 포함되어 공개 저장소에 올리지 않고 별도로 전달합니다.
