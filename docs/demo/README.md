# GMG 소개와 시연 자료

**[GMG 대표 홍보 영상 — 1분](GMG-launch-film.mp4)** · [구성과 제작 설명](LAUNCH-FILM.md)

타이포·경로 애니메이션과 실제 앱 화면으로 프로젝트를 소개하는 대표 영상입니다. 11월 12일 수정본에는 통일한 한글 자막과 구간별 배경음, 전환·강조·엔딩 효과음 18개를 반영했습니다.

2026년 11월 11일 자막과 화면 배치를 검토한 수정본입니다.

[프로젝트 소개 영상](GMG-overview.mp4) · [기능 시연 영상](GMG-walkthrough.mp4) · [실제 앱 화면 모음](GMG-screens.png)

[영상 수정 및 3회 검수 결과](REVIEW.md)

영상은 1920×1080, 초당 30프레임의 H.264 MP4입니다. 한국어 설명 자막을 영상에 직접 렌더링했습니다. 휴대폰 웹 구간은 실제 화면 캡처이며, 차량 앱 구간은 Pleos Connect 에뮬레이터의 실제 조작 녹화입니다.

## 수정한 부분

- 한글 글꼴과 자막 크기를 통일하고, 어절 단위 줄바꿈과 자막 영역을 점검했습니다.
- 영상별 장면 번호를 1부터 시작하고, 제목·본문·보조 설명의 위치를 고정했습니다.
- 도착 확인, 재실행 후 복원, 방문 완료, 다음 장소 순서로 장면을 정리했습니다.
- 앱 재실행 중 잠깐 비는 화면을 제외하고, 장면별 재생 시간을 고정했습니다.
- 완성본 전체를 동일한 색상 설정과 H.264 형식으로 다시 인코딩했습니다.

## 촬영 범위

관람료는 시연에서 직접 입력한 값입니다. 주차요금은 선택한 시간·차량 조건의 예상 금액이며, 미확인 항목을 함께 표시합니다. 내비 시연 범위는 출발 전 목적지 확인 화면까지입니다.

공개 화면은 별도 시연용 모임을 사용했으며, 해당 모임은 촬영 후 폐기했습니다.
