# GMG 소개와 시연 자료

2026년 11월 11일 기준 구현 화면을 담은 제출 참고자료입니다.

[프로젝트 소개 영상](GMG-overview.mp4) · [기능 시연 영상](GMG-walkthrough.mp4) · [실제 앱 화면 모음](GMG-screens.png)

영상은 1920×1080 MP4 형식이며 한국어 설명 자막으로 구성했습니다. 휴대폰 웹 부분은 실제 화면 캡처이고, 차량 앱 부분은 Pleos Connect 에뮬레이터에서 직접 조작한 녹화입니다.

관람료는 시연에서 직접 입력한 값입니다. 주차요금은 선택한 시간·차량 조건의 예상 금액이며, 미확인 항목을 함께 표시합니다. 길 안내는 차량 내비에 전달하기 전 목적지 확인 화면까지 보여 줍니다.

공개 화면은 별도 시연용 모임을 사용했습니다. 영상에 사용한 모임은 녹화 후 폐기했습니다. 실제 사용자 모임과 초대 인증정보는 자료에 포함하지 않았습니다.
