# 모아길 공유 서버와 휴대폰 웹

QR로 같은 모임에 참여해 장소를 찾고 관심을 표시하거나 비밀 투표에 참여하는 웹입니다. 차량 앱과 모임 데이터를 공유합니다.

## 실행

Node.js 22 이상을 사용합니다. 외부 npm 의존성 없이 실행할 수 있습니다.

```sh
node server.mjs
```

기본 주소는 `http://localhost:8787`입니다. 모임은 차량 앱에서 생성하고 초대 QR로 휴대폰에 연결합니다. Android 에뮬레이터의 서버 주소는 `http://10.0.2.2:8787`입니다.

## 지도와 자동차 경로

`.env.example`을 `.env`로 복사한 뒤 필요한 키를 입력합니다.

- `KAKAO_REST_API_KEY`: 장소 검색용 서버 키.
- `KAKAO_JAVASCRIPT_KEY`: 웹 지도용 키. 사용하는 웹 도메인을 카카오 개발자 콘솔에 등록합니다.
- `KAKAO_MOBILITY_REST_API_KEY`: 자동차 경로용 키. 비어 있으면 REST 키를 사용하며, 해당 API 사용 권한이 필요합니다.

서버 키는 브라우저로 전달하지 않습니다. JavaScript 지도 키는 클라이언트에 노출되는 키이므로 도메인을 제한해야 합니다. 실제 키와 `.env`는 Git에 올리지 않습니다.

## 휴대폰 QR 접속

휴대폰에서 접근할 수 있는 PC의 특정 네트워크 주소를 `HOST`에, 같은 주소의 웹 URL을 `PUBLIC_URL`에 지정합니다. 아래 주소는 설정 예시입니다.

```powershell
$env:HOST='192.168.0.10'
$env:PUBLIC_URL='http://192.168.0.10:8787'
$env:PHONE_SHARE_UNTIL=[DateTimeOffset]::UtcNow.AddMinutes(30).ToUnixTimeMilliseconds().ToString()
node server.mjs
```

- PC 내부 수신과 지정한 주소에서만 수신하며 `0.0.0.0` 및 `::` 전체 인터페이스 수신은 거부합니다.
- 임시 네트워크 수신은 최대 30분 뒤 자동으로 닫히고, PC 내부 서버는 유지됩니다.
- 휴대폰에서 접근할 네트워크와 방화벽 설정은 실행 환경에 맞게 확인해야 합니다.
- 초대 링크를 가진 사람은 해당 모임의 장소·이름·투표 정보에 접근할 수 있습니다. 링크 재발급·참여 종료·기록 삭제는 차량의 모임 관리에서 할 수 있습니다.
- 개발 환경의 HTTP 공유 예시입니다. 운영 환경은 HTTPS와 별도의 배포 구성이 필요합니다.

## 사용 흐름

1. 차량에서 초대 QR을 엽니다.
2. 휴대폰에서 이름과 공유 항목을 확인하고 장소를 검색·추가합니다.
3. 하트로 관심을 표시하거나 차량에서 시작한 비밀 투표에 참여합니다.
4. 차량에서 목적지 또는 코스를 선택하고 출발을 확인합니다.

메모·운영시간·머무를 시간은 장소 추가창의 선택 항목에 있습니다. 자동 영업정보 조회는 아직 연동하지 않았습니다. 삭제는 차량에서 할 수 있으며 직후 되돌리기와 최근 삭제 복원을 지원합니다.

## 코스 계산

필수 장소와 관심 표시 수를 기준으로 최대 5곳을 고르고 방문 순서를 비교합니다. 카카오 도로 구간을 조회할 수 있으면 도로 예상시간과 입력한 운영시간을 사용합니다. 조회 실패 시 임시 이동시간 및 직선 동선 사용 여부를 표시합니다. 영업 시작 전 대기와 음식점 대기 줄은 서로 다른 개념이며 실제 줄·주차 대기는 예측하지 않습니다.

## 검사

```sh
node --test test/server.test.mjs test/session.test.mjs test/brand-contrast.test.mjs
```

`test/usability-preview.mjs`는 가상 데이터와 의도적인 검색 실패를 제공하는 로컬 검증 서버입니다. 실제 모임 데이터와 분리해 실행하고 제한 시간이 지나면 임시 자료를 정리합니다. Android 검사 스크립트는 로컬 SDK 경로와 별도 검증용 모임 파일이 필요합니다.

## 저장 자료

실제 모임 기록은 `data/rooms.json`에 저장됩니다. 이 폴더는 Git에서 제외하며 개인 백업으로 관리해야 합니다. 실행 로그·초대 토큰·QR 캡처도 저장소에 포함하지 않습니다.
