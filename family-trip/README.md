# GMG 공유 서버와 휴대폰 웹

QR로 같은 모임에 참여해 장소를 찾고 차량에 추가하는 지도 중심 웹입니다. 차량 앱과 모임 데이터를 공유합니다.

## 실행

Node.js 22 이상을 사용합니다. 외부 npm 의존성 없이 실행할 수 있습니다.

```sh
node server.mjs
```

기본 주소는 `http://localhost:8787`입니다. 모임은 차량 앱에서 생성하고 초대 QR로 휴대폰에 연결합니다. Android 에뮬레이터의 서버 주소는 `http://10.0.2.2:8787`입니다.

## 지도와 자동차 경로

`.env.example`을 `.env`로 복사한 뒤 필요한 키를 입력합니다.

- `KAKAO_REST_API_KEY`: 장소 검색용 서버 키.
- `KAKAO_JAVASCRIPT_KEY`: 웹 지도용 키. 사용하는 웹 도메인을 카카오 개발자 콘솔에 등록합니다.
- `KAKAO_MOBILITY_REST_API_KEY`: 자동차 경로용 키. 비어 있으면 REST 키를 사용하며, 해당 API 사용 권한이 필요합니다.

서버 키는 브라우저로 전달하지 않습니다. JavaScript 지도 키는 클라이언트에 노출되는 키이므로 도메인을 제한해야 합니다. 실제 키와 `.env`는 Git에 올리지 않습니다.

## 휴대폰 QR 접속

휴대폰에서 접근할 수 있는 PC의 특정 네트워크 주소를 `HOST`에, 같은 주소의 웹 URL을 `PUBLIC_URL`에 지정합니다. 아래 주소는 설정 예시입니다.

```powershell
$env:HOST='192.168.0.10'
$env:PUBLIC_URL='http://192.168.0.10:8787'
$env:PHONE_SHARE_UNTIL=[DateTimeOffset]::UtcNow.AddMinutes(30).ToUnixTimeMilliseconds().ToString()
node server.mjs
```

- PC 내부 수신과 지정한 주소에서만 수신하며 `0.0.0.0` 및 `::` 전체 인터페이스 수신은 거부합니다.
- 임시 네트워크 수신은 기본 30분, 명시한 종료 시각에 따라 최대 24시간 뒤 자동으로 닫히고, PC 내부 서버는 유지됩니다.
- 휴대폰에서 접근할 네트워크와 방화벽 설정은 실행 환경에 맞게 확인해야 합니다.
- 초대 링크를 가진 사람은 해당 모임의 장소·이름·투표 정보에 접근할 수 있습니다. 링크 재발급·참여 종료·기록 삭제는 차량의 모임 관리에서 할 수 있습니다.
- 개발 환경의 HTTP 공유 예시입니다. 운영 환경은 HTTPS와 별도의 배포 구성이 필요합니다.

## 사용 흐름

1. 차량에서 초대 QR을 엽니다.
2. 휴대폰 지도에서 장소를 검색하고 핀이나 검색 결과를 선택합니다.
3. 장소 공유에 동의하고 차량에 추가합니다. 이름·메모·투표 입력은 없습니다.
4. 차량에서 목적지 또는 코스를 선택하고 출발을 확인합니다.

휴대폰에서는 검색·추가와 추가한 장소 확인만 할 수 있습니다. 이름·메모 수정과 삭제는 차량에서 제공하며, 완료 코스의 기록을 보존하고 목록에서 제거합니다. 진행 중인 코스의 경유지를 삭제하면 재계산이 필요하다고 표시합니다. TourAPI 등록 장소의 운영정보를 조회할 수 있으며, 조회한 자유문은 코스 계산에 자동 반영하지 않습니다.

## 코스 계산

필수 장소와 관심 표시 수를 기준으로 최대 5곳을 고르고 방문 순서를 비교합니다. 카카오 도로 구간을 조회할 수 있으면 도로 예상시간과 입력한 운영시간을 사용합니다. 조회 실패 시 임시 이동시간 및 직선 동선 사용 여부를 표시합니다. 영업 시작 전 대기와 음식점 대기 줄은 서로 다른 개념이며 실제 줄·주차 대기는 예측하지 않습니다.

## 검사

```sh
node --test test/server.test.mjs test/session.test.mjs test/brand-contrast.test.mjs test/place-management.test.mjs test/place-info.test.mjs
```

`test/usability-preview.mjs`는 가상 데이터와 의도적인 검색 실패를 제공하는 로컬 검증 서버입니다. 실제 모임 데이터와 분리해 실행하고 제한 시간이 지나면 임시 자료를 정리합니다. Android 검사 스크립트는 로컬 SDK 경로와 별도 검증용 모임 파일이 필요합니다.

## 저장 자료

실제 모임 기록은 `data/rooms.json`에 저장됩니다. 이 폴더는 Git에서 제외하며 개인 백업으로 관리해야 합니다. 실행 로그·초대 토큰·QR 캡처도 저장소에 포함하지 않습니다.

### 가게 정보 (2026-10-28)
카카오 검색 결과의 업종·전화번호·상세페이지·조회 시각을 서버가 확인해 저장합니다. 기존 장소는 차량 상세 화면의 정보 불러오기에서 이름·좌표를 대조합니다. 웹 하단 카드의 정보 버튼에서도 확인할 수 있습니다. 영업시간·메뉴·리뷰 자동 수집은 아직 제공하지 않으며, 상세페이지로 연결합니다. 임의 링크나 클라이언트가 보낸 가게 정보는 신뢰해 저장하지 않습니다.

### TourAPI 운영정보 연동
- 공공데이터포털 `한국관광공사_국문 관광정보 서비스_GW` 인증키(Decoding)를 `.env`의 `TOUR_API_KEY`에 저장한 뒤 서버를 재시작합니다. 키는 서버에서만 사용합니다.
- 장소 상세 화면의 `영업시간·휴일·요금 조회`로 운영정보를 조회합니다. 웹에서도 저장한 장소의 정보 화면에서 사용할 수 있습니다.
- 공식 KorService2의 위치/키워드 검색 후 이름과 150m 이내 좌표를 대조합니다. 동일 지점이 하나로 확인된 경우에만 소개정보와 요금 관련 반복정보를 연결합니다. 여러 후보가 겹치면 자동 연결하지 않습니다.
- 음식점 영업시간·휴일·메뉴, 관광지/문화시설/레포츠 이용시간·휴무·요금, 숙박 입실/퇴실 등 제공된 원문만 표시합니다. 가격이 없으면 무료로 해석하지 않습니다. 모든 일반 매장이 등록된 서비스는 아닙니다.
- 조회 결과는 24시간 캐시합니다. 발급 직후 승인이나 키 적용이 지연되면 잠시 후 다시 조회하세요. 출처와 조회일을 표시하며, API가 반환한 자유문 영업시간은 아직 코스 제약으로 자동 변환하지 않습니다. 기존 직접 입력한 방문 조건을 덮어쓰지 않습니다.
- 실제 인증키 검증: 경복궁 이용시간·휴일·요금 응답 확인. 당시 모임의 장소 3곳은 동일 지점 확인 실패로 미연결.
