# GMG 태블릿 체험

갤럭시 탭 S8+ 등 일반 Android 태블릿에서 차량 앱의 화면과 흐름을 경험하는 독립 개발용 프로젝트입니다. `PleosStarter`의 스냅샷을 복사했으며 원본의 소스·패키지·앱 데이터·주행 제한 로직을 변경하지 않습니다.

- 별도 설치 이름: **GMG 체험**
- 별도 패키지: `com.gmg.tablet.experience`
- 별도 체험 데이터: `TabletExperience/data/` (Git 제외)
- 실제 차량 공조 및 Pleos 내비 SDK 연결은 하지 않습니다. 장소의 지도 보기와 길 안내 요청은 지도 앱/브라우저로 넘깁니다. 경로 안내가 시작되었다고 자동 판정하지 않습니다.
- 장소·코스 관리 기능과 폰에서 장소를 추가하는 QR 흐름은 독립 체험 모임에서 사용합니다. 체험용 세션 API는 이 모임의 관리 권한만 제공하므로 개인 차량 기록을 가져오지 마세요.
- 공유 시간에는 같은 체험 서버에 접속한 사람이 체험 모임을 수정할 수 있습니다. API 키는 APK에 넣지 않으며 장소 검색·경로 계산은 PC 서버가 처리합니다.

## 빌드

`build-tablet.ps1 -ServerUrl 'http://PC주소:8789'`

결과: `app/build/outputs/apk/debug/app-debug.apk`. 별도 개발 서명 APK이며 일반 태블릿에 설치할 수 있습니다. 실제 탭 S8+ 설치 검증은 기기 연결 후 진행합니다.

## 서버

`tablet-server.mjs`를 Node.js로 실행합니다. 기본값은 localhost 전용입니다. 외부 연결에는 `TABLET_HOST`에 특정 PC 주소, `PHONE_SHARE_UNTIL`에 종료 Unix 밀리초를 명시해야 합니다. 8789 포트의 공유 리스너는 종료 시각에 닫힙니다. PC 서버가 꺼지면 실시간 검색·동기화는 사용할 수 없습니다.
