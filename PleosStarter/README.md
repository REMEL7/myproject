# GMG Android 앱

Pleos Connect에서 실행하는 Kotlin Activity 앱입니다. 친구·가족·동료가 휴대폰에서 모은 장소를 차량에서 확인하고 목적지 또는 코스로 정한 뒤 기본 내비로 보냅니다.

## 환경

- Java 17, Kotlin 2.2.10.
- Gradle Wrapper 9.6.0, Android Gradle Plugin 9.4.1.
- compileSdk 36, targetSdk 34, minSdk 28.
- Vehicle 2.3.2, NaviHelper 3.0.5, ZXing 3.5.3.
- Pleos Connect 에뮬레이터 v2.1.0에서 개발·검증. 전체 화면 2560×1440 px, 160 dpi.

## 실행

1. Android Studio에서 이 폴더를 엽니다.
2. Java 17과 Android SDK 경로를 설정합니다. `local.properties`는 각 환경에서 생성합니다.
3. Gradle Sync 후 Pleos Connect 에뮬레이터에 `app`을 실행합니다.
4. [공유 서버](../family-trip/README.md)를 PC에서 실행합니다.

기본 실행 화면은 `FamilyTripActivity`입니다. 기본 서버 주소는 `http://10.0.2.2:8787`이고 고급 설정에서 바꿀 수 있습니다.

```powershell
.\gradlew.bat assembleProductionDebug
```

상위 `.tools/java17`에 로컬 Java를 준비한 환경에서는 `build-debug.ps1`도 사용할 수 있습니다. 해당 개발 도구 폴더는 Git에 포함하지 않습니다.

## 주요 화면

- 홈: 앱 이름과 간단한 시작 안내.
- 장소: 목록·상세 정보·이름과 메모 수정·삭제·되돌리기·출발 확인.
- 코스: 방문 순서 비교·저장·이어가기·방문 완료·일정 관리.

화면 크기에 따라 목록이 재배치되며 분할 화면을 지원합니다. 차량의 주행 제한 상태를 확인하고 주차 상태에서만 조작할 수 있습니다. 상태를 확인할 수 없으면 조작을 제한합니다. 실제 안내 시작은 사용자 확인을 거쳐 Pleos 기본 내비에 전달합니다.

완료된 코스에 속한 장소도 목록에서 삭제할 수 있으며, 완료 기록은 유지합니다. 진행 중인 코스의 남은 장소를 삭제하면 다시 계산이 필요하다고 표시하고 오래된 도착 계획으로 출발하지 않도록 합니다.

## 코스 팝업

코스 홈은 저장한 코스·다음 장소와 코스 만들기 진입점으로 정리했습니다. 장소 선택 → 주차 선택 → 코스 확인의 세 단계는 큰 중앙 팝업을 사용합니다. 사용자가 선택한 1~5곳만 포함하고 주차장 지정 여부·거리·30분/1시간/2시간 예상요금을 비교합니다. 시간·거리 우선 코스를 저장하면 선택한 주차장 좌표를 차량 내비 목적지로 전달합니다. 세부 계산 기준과 데이터 한계는 `DATA_SOURCES.md`를 참고하세요.

## Virtual Console

`start-virtual-console.ps1`은 설정한 Pleos AVD를 찾아 실행하고, 콘솔의 8088 포트를 전달한 뒤 브라우저를 엽니다. SDK 경로나 AVD 이름이 다르면 인자로 지정합니다. Android Studio를 별도로 시작하지 않습니다.

## 개발용 구성

`MainActivity`의 차량 SDK 예제와 오버레이·위젯 실험 코드를 조사 목적으로 보존합니다. 현재 제품의 기본 화면은 GMG이며, 내비 위 실제 오버레이 표시를 완료한 기능으로 안내하지 않습니다.

글레오 스키마와 액션은 개발 단계입니다. 실제 음성 호출은 등록·승인과 지원 기기 검증이 필요합니다.

## Release

공모전 심사용 `submissionRelease`는 [심사용 APK 실행 안내](../docs/SUBMISSION.md)를 따릅니다. 비공개 키로 서명하며 디버깅을 허용하지 않습니다. 패키지 `com.example.pleosstarter.submission`으로 기존 앱과 분리하고, `http://10.0.2.2:8787`만 PC 로컬 릴레이 예외로 허용합니다. 일반 `productionRelease`는 아래 HTTPS 검증을 유지합니다.

`MOAGIL_SERVER_URL`에 HTTPS origin을 지정하고 다음 서명 환경 변수를 준비해야 합니다.

- `MOAGIL_KEYSTORE`
- `MOAGIL_STORE_PASSWORD`
- `MOAGIL_KEY_ALIAS`
- `MOAGIL_KEY_PASSWORD`

서명 파일과 값은 Git에 올리지 않습니다. 운영용 서버와 인증·배포 구성은 별도 준비가 필요합니다.

### 장소 선택 접근성 개선
출발·삭제·관리·수정·방문 조건은 애니메이션 없는 중앙 팝업으로 표시하며, 주요 확인 버튼은 높이 56 앱 단위를 사용합니다. 즐겨찾기 UI는 제거했습니다. 분류는 맛집(🍚), 카페(☕), 가볼 곳(🏞️), 숙소(🏨), 기타(📍)이며 알 수 없거나 비어 있는 분류도 기타로 표시합니다. 좁은 창에서도 팝업이 창 안에 맞춰집니다.

### 코스 삭제
코스 홈과 코스 상세의 ‘코스 삭제’에서 큰 중앙 확인 팝업을 엽니다. 차량 진행자만 현재 코스 ID를 확인해 삭제하며 저장 코스·방문 기록·비교 후보를 지우고 장소 목록과 투표 기록은 보존합니다. 진행 중·완료 코스 모두 지원하며 삭제는 서버에 저장됩니다. 기본 내비의 실행 중 안내를 종료하는 기능과는 별개입니다.

### 가까운 주차장과 비용 확인
코스의 주차·비용 화면은 출발지와 성인 인원 설정, 장소별 주차장·관람료로 정리했습니다. 직선거리상 가장 가까운 주차장을 기본 선택하고 변경·주차 안 함을 지원합니다. 주차요금과 코스의 확인된 비용을 큰 굵은 글씨로 표시합니다. 관람료 원문 확인·성인 1인 요금 입력·성인 인원별 계산을 지원하며, 시간·거리 비교는 같은 화면의 선택 막대로 전환합니다. 미확인 비용은 무료로 표시하지 않습니다.

코스 만들기는 1/3 장소 → 2/3 주차·비용 → 3/3 코스 선택으로 이어집니다. 비교 기준은 시간·거리·예상비용 세 가지이며, 이전 단계로 돌아가도 입력·선택 기준을 유지합니다. 출발지를 뒤늦게 고른 경우 비교 단계로 바로 이어집니다. 같은 단계에서 정보가 갱신되면 창을 닫았다 다시 띄우지 않고 내용을 갱신합니다. 비용 우선은 자동 주차장 선택의 확인된 요금만 비교하며 자세한 범위는 DATA_SOURCES.md를 따릅니다.

팝업은 흰색 제목·본문과 옅은 경계선으로 통일하며 뒤 화면을 어둡게 해 구분합니다. 큰 팝업 최대 폭은 660 앱 단위, 단일 하단 버튼은 높이 56·최대 폭 300 앱 단위로 오른쪽에 배치합니다. 선택 행과 비교 기준의 여백도 줄이고, 비활성 버튼은 옅게 표시합니다.
